---
title: Upgrading to 3.0
description: Replace the compatibility aliases removed by Laravel AI Engine 3.0.
---

Laravel AI Engine 3.0 removes six compatibility surfaces deprecated throughout
the 2.x release line:

| Removed | Replacement |
| --- | --- |
| chat request `async` | `execution_mode=sync|async|auto` |
| chat request `rag` | `use_rag` |
| `LaravelAIEngine\Facades\AIEngine` | `LaravelAIEngine\Facades\Engine` |
| `AIEngineFake::requests()` | `AIEngineFake::calls()` |
| `ai-agent.ai_native.enabled` | remove it; AI-native is always active |
| raw `agent_context:{session}` cache reads | scoped `AgentContextRepository` keys |

Unknown Agent Chat fields are ignored rather than translated. Update every
payload before deploying 3.0. Clear or wait out raw legacy context-cache keys;
3.0 never reads or deletes them.

The classic routing brain, old `ConversationService` alias, package-coded
`SkillFlowRunner`, and action-draft workflow tools were already removed.

`prompt_json`, provider shortcuts, the MCP tool-call endpoint, the realtime
tool-dispatch endpoint, provider-tool runs, and agent runs remain supported.

Verify the cutover with:

```bash
php artisan ai:compatibility --json
php artisan ai:compatibility --fail-on-deprecated
```

Both commands succeed on 3.0 and report `deprecated_count: 0`.
